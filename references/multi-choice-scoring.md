# 多选题判分规则 · 强制前馈对齐（最高优先级前馈项）

## 为什么单独成篇

这是整个发布流程里**最容易出错、且错了代价最大**的一项：系统在发布设置页提供四种多选给分规则，而命题／纸质卷在出题时已经按某一种规则写死了说明和分值。两者一旦不一致，成绩就是错的；而**发布后题量、分值、发放对象基本锁死，纸质卷也已经印刷**，改不回来。

本次实战的教训（用户原话）：
> "多选题这里面是怎么给分的，而我题里出的是怎么给分的，它俩能统一吗？有几种形式对吧，你得问好、看好它，然后再做……这块得分规则要变的话，那我纸质版的试卷得分规则就得变对不对？"

**因此本项必须在智能导入之前完成，不许拖到发布设置页才临时决定。** 决策顺序是：先定规则 → 再定纸卷说明 → 最后导入并在系统里按同一规则设置。

## 第一步：认识系统的四种规则（先让用户看清楚）

学习通发布页多选给分规则，由"多选题未选全得一半分"勾选框 + `multiHalfScore` 下拉共同决定，共四种：

| # | 系统规则 | 勾选/字段设置 | 含义 | 纸质卷对应说明（参考措辞） |
|---|---|---|---|---|
| 1 | **全选对才给分** | 不勾 `multiHalfScoreCheckbox` | 少选、多选、错选都 0 分 | "多选、少选、错选均不得分" |
| 2 | **未选全得一半分** | 勾选 + `multiHalfScore`=0 | 少选（未选全但无错选）得该题一半分，错选 0 分 | "少选得一半分，错选/多选不得分" |
| 3 | **得指定比例分** | 勾选 + `multiHalfScore`=2 + 填 `multiScoreRatio` | 少选得该题指定百分比分 | "少选得该题 {X}% 分，错选不得分" |
| 4 | **按选对数量得分** | 勾选 + `multiHalfScore`=3 | 每选对一个得相应分，错选另有规则 | "每选对一个得 {X} 分，错选倒扣/不得分" |

> 相关同类项一并确认：排序题按空给分（`sortAvgScore`）、填空题按空打分（`reviewByBlank`）——逻辑相同，规则要与题目设计一致。

## 第二步：强制对齐三问（必须逐条回答，不许跳过）

在导入前，向用户**明确逐条确认**下面三件事，并把答案写进台账。任一答不出或前后矛盾 → 停下来问，不要往下走：

- **对齐问 1 · 题目怎么设计的？**
  拿出纸质卷／参考答案，逐题确认：多选题的评分说明写的是哪一种？（全对才给／少选一半／指定比例／按选对数量）**以纸卷实际文字为准，不以记忆为准。**

- **对齐问 2 · 系统要设成哪种？**
  四种里选一种，与对齐问 1 对应。若题目设计是规则 1 而用户想用规则 2，或反之——**这是冲突，必须显式提出**：要么改系统设置，要么改纸卷说明并重新印刷，请用户裁决，不许自行选一个。

- **对齐问 3 · 纸卷说明要不要跟着改？**
  如果最终系统规则与纸卷原说明不同，明确告知用户："纸质卷的'少选得一半、错选0分'之类说明必须同步改成规则 X 的措辞，否则学生按纸卷理解、系统按另一套给分，必然出错。"**记下这条待办，发布后补做**（本次就是把纸卷说明留作发布后统一补）。

## 第三步：确认后落盘（照单填写，不再临时改）

确认通过后，把结论写进前馈答案清单，例如：

```
多选题给分：规则 2（未选全得一半分）
  系统设置：multiHalfScoreCheckbox ✓ + multiHalfScore=0
  纸卷原说明：少选得一半分、错选0分 → 与规则2一致 ✓
  待办：无（若不一致，写明"发布后补改纸卷说明为规则X"）
```

后续在发布页按这张单子填 `multiHalfScoreCheckbox`／`multiHalfScore`／`multiScoreRatio`，**并在发布前终检单 C1/C2 再核对一次**——这是同一件事的两道关：前馈时定规则，终检时验规则确实落到了系统且与纸卷一致。

## 用户本次的决定

规则 2：未选全得一半分（`multiHalfScoreCheckbox` 勾选、`multiHalfScore`=0）。纸卷"少选得一半、错选0分"说明本就与该规则一致，但**发布后仍统一补一遍措辞**，确保学生看到的说法和系统完全一致。
