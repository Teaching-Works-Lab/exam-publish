# 执行流程与不可逆提交点

## 总体顺序

```
个人空间 → 线下系统题库管理（建库）
        → 试卷管理 → 新建试卷/组卷
        → 智能导入 Word（跳 mooc2-ans 再回跳线下）
        → 识别 → 逐题填分 → 加入试卷（不可逆①）
        → 预览核对 → 试卷管理列表
        → 发布考试：开线下开关 → 填设置 → 加班级 → 须知 → 下一步
        → 发布前终检 → 发布（不可逆②）
        → 发通知（不可逆③）→ 答题纸／批阅设置
```

## 三个不可逆提交点（必须停下问用户）

### ① 加入试卷（智能导入提交）

- **位置**：智能导入页，识别结果 24 题无误、24 个分值框填完后，右下角"加入试卷"。
- **提交前**：核对识别条数、题型分布、每题分值、总分 100；确认 Q1 给分规则与题目设计不冲突。
- **弹窗**：可能出现的"新题型确认"用 `a#confirmMove`；导入成功确认 `a#confirmImport`。
- **问用户**："识别与分值核对通过，是否提交入库？"
- **提交后**：断言"共 24 条导入成功"、试卷ID 生成、题量 24、满分 100；预览分值分块 16+8+6+40+30。

### ② 发布考试

- **位置**：发布页第二步，`a#submitButton`（`.publishSubmitButton`）。
- **注意**：该按钮在**第一步是隐藏的**（`display:none`，零尺寸），只有进入第二步才可点击。在第一步点会报"zero-sized bounding box"。
- **提交前**：走完 `pre-publish-checklist.md` 全部条目，取得用户授权。
- **发布逻辑**：`pubishExam()` 按 `examlx=1` 走 `pubishExamlx1()`；校验线下字段、时限≤窗口、及格≤满分等。
- **发布后**：弹窗"考试发布成功，是否发放考试通知？"

### ③ 发放通知

- **流程**：发布成功弹窗点"是" → 进入"发送通知"对话框 → 填接收人／通知标题／通知内容 → 确定 → 跳回考试管理列表。
- **文案**：按 Q6，标题／正文不写 A/B 卷。
  - 标题：`智能制造装备期末考试通知`
  - 正文：`考试名称：智能制造装备期末考试` + 时间（含答题时长）+ 地点 + 主/副监考 + 线下说明。
- **注意**：通知标题输入框是 `#notice_title`（name=`text`）；页面有多个 `input[name="text"]`，**不要用 `querySelector('input[name="text"]')` 定位**，会选错元素。正文是 `textarea#notice_context`。
- **发后**：考试管理列表确认该考试存在、人数正确。若用户不想发，弹窗点"否"，之后可在考生管理页"发送考试通知"补发。

## 建库与组卷要点

- 线下题库：题库管理 → 创建新的库（界面文字是"创建新的库"，不是"创建新题库"）→ 库名"智能制造装备"。记下题库ID（269637241）／tkid（1496984）。
- Word 底稿**不写分**；分值全部在智能导入页填（见 `platform-pitfalls.md`）。
- 新试卷在试卷管理里叫"新建试卷<时间戳>"，可在列表重命名；内部 `paperid` 才是稳定标识。
