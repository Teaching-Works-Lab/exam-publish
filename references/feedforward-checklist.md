# 前馈清单（动手前一次性问清）

## 什么是前馈，为什么它比"做到那一步再问"重要

**前馈 = 在流程开始前，把所有"做到一半才会暴露、且一旦定了就影响后面每一步"的决策，一次性向用户问清并锁定。**

本次实战的教训：多选题给分规则是在发布设置页才发现的，但那时纸质卷已经印好、题目给分已经按另一种规则写死——用户明确指出"这块得分规则要变的话，那我纸质版的试卷得分规则就得变"。类此，是否流水批、学生端可见什么、发给哪些班，都是"发布后才发现问题就大了"的项。

**使用方式**：接到任务先把本清单过一遍，把答案填进"确认答案清单"（可写到台账里）。后续所有设置照单填写。任何一项用户没给答案 → 问，不要猜默认值。答案之间有冲突 → 回报冲突请用户裁决。

## Q0 系统与考试形式（最先确认，判错全盘错）

- **问**：这是课程内在线考试，还是线下纸考／网评？有没有答题卡、监考、纸质试卷？
- **为什么**：两套系统不通用。线上在 `mooc2-ans` 课程内；线下在 `v10596.kaoshi.chaoxing.com`。本次最初误判为线上，用户纠正。
- **判据**：见 SKILL.md「阶段 0」。用户明确说的话以用户为准。
- **影响**：决定整个操作入口、字段体系（线下 `_lx1`）、是否需要答题纸。

## Q1 多选题给分规则（最高优先级前馈项 · 必须强制对齐）

> **本项最重要，单独成篇：先读 `multi-choice-scoring.md`，完成"强制对齐三问"后才可进入智能导入。不许拖到发布设置页才临时决定。**

- **问**：多选题怎么给分？系统支持四种——① 全选对才给分；② 未选全得一半分；③ 得指定比例分；④ 按选对数量给分。你要哪一种？**题目／纸卷设计里是按哪一种写的？两者是否一致？纸卷说明要不要跟着改？**
- **为什么**：**系统规则必须和题目／纸质卷设计一致**。若题目按"少选得一半"设计而系统设成"全对才给分"，成绩会错；反过来改系统规则就要同步改纸质卷说明，发布后纸卷印错来不及。这是全链路错了代价最大、且发布后不可挽回的一项。
- **必须做的强制对齐**：逐条回答 `multi-choice-scoring.md` 的"对齐三问"（题目怎么设计 → 系统设哪种 → 纸卷改不改）；若系统规则与纸卷设计冲突，显式上报用户裁决，不自行选一个。
- **本次答案**：规则②未选全得一半分（`multiHalfScore`=0，`multiHalfScoreCheckbox` 勾选）；纸卷"少选得一半、错选0分"说明与该规则一致，仍决定发布后统一补一遍措辞。
- **两道关**：前馈时定规则（本篇），发布前终检单 C1/C2 再核对规则确实落到系统且与纸卷一致。
- **相关**：排序题按空给分（`sortAvgScore`）、`reviewByBlank` 填空按空打分也是同类前馈，一并确认。

## Q2 批阅模式与人员（是否流水批、几人教、几人监考）

- **问**：
  1. 普通批阅（一人批完整卷）还是流水批／按题分配（多人各批一部分）？整卷批还是流水批？
  2. 这门课几位老师教？是否多人共教一门课，需要分配各自批哪些题／哪些班？
  3. 是否多人监考？是否把监考教师／组卷教师／网络课程创建教师同步设为阅卷教师？
  4. 是否开启简答类 AI 批阅？
- **为什么**：决定批阅教师分配、快速分配方式、阅卷教师同步开关。多人共教一门课若不提前定批阅分工，考后批卷会扯皮。
- **本次答案**：本人一门课独立授课 → 普通批阅、整卷批；AI 批阅关；快速分配"普通分配"；未同步监考教师为阅卷教师。
- **详见**：`review-modes.md`。

## Q3 学生端可见性与考后查看（本次重点前馈项）

- **问**：发布后学生端能看到什么？考后是否允许看试卷／答案／分数／对错／答题纸／等级？
- **为什么**：线下纸考的正确语义是——学生只看到考试通知／须知（通常为"线下考试，无需线上作答"），**看不到卷子**。其他老师反馈"学生反映没看到"，本质是学生端本来就只显示通知，不是发布失败。
- **本次答案**：考后查看全部关闭（试卷／提交后答案／截止后答案／总分／对错／答题纸／等级全关）。
- **落地**：`allowScore` / `allowLookObjScore` / `allowLookpaper` / `allowViewRightwrong` / `allowLookAnswersheet` / `allowLookExamGrade` 全部不勾。

## Q4 发放对象：涉及哪些班级

- **问**：这次考试发给哪些班级？每班多少人？是否按网络课程班级分别发放、是否按教学班分组？名单来源（网络课程／学生库／批量导入 Excel）？
- **为什么**：发布后班级／人数不可随意改；名单必须在答题纸扫描前上传完成。批量导入 Excel 有"组别"列（建议按行政班划分），重新导入会覆盖已有分组。
- **本次答案**：智能23 一个班，63 人，从网络课程添加（`classids=155688692`），按网络课程班级分别发放。
- **坑**：页面可能显示"已添加考生0人"，但底层 `classids` 已写入、考生管理页实测 63 人——属显示假象，不要因此重复添加。

## Q5 分值与给分可行性

- **问**：分值方案是什么？主观题（简答／综合）能否低于预设满分给分？Word 底稿写不写分？
- **为什么**：Word 底稿不写分，分值在智能导入页逐题填；已验证主观题可低于满分给分（10 分题能给 4 分），预设分值不是必给分。满分总和要=100。
- **本次答案**：单选8×2 + 多选4×2 + 判断6×1 + 简答4×10 + 综合2×15 = 100。

## Q6 学生可见文案是否回避 A/B 卷（本次用户新增的明确要求）

- **问**：面向学生的考试名称／通知标题／通知正文／须知，是否回避"A 卷／B 卷"字样？
- **为什么**：用户明确："这个写的时候不要写 A 卷 B 卷，他们只知道什么考试就可以了。"学生对内部 A/B 卷编号无感，看到反而困惑。
- **本次答案**：通知标题"智能制造装备期末考试通知"、正文"考试名称：智能制造装备期末考试"——不出现 A 卷。系统内部考试名称仍保留"A 卷"（教师侧标识用）。
- **落地范围**：**所有学生可见文案**（通知、须知、学生端任务名）；教师侧系统名称不受此约束。

## Q7 课程名称／学期／批次／场次是否必填

- **问**：这些选填项要不要填全？
- **为什么**：用户曾要求"把该填信息填成全的"。实际核查：这些是选填（`verifyCourse`/`verifySemester`/`verifyBatch` 均为 0），教务下拉无数据时无法填。
- **本次答案**：经核查为选填且教务下拉无数据 → 用户决定留空。 semester 默认当前学期（2026-2027 学年第一学期）已自动带出。
- **做法**：先查 verify 标志与下拉是否有数据；有数据按用户要求填，无数据说明情况后留空，不卡住流程。

## Q8 题号连续性与前后透题

- **问**：客观题题号要全局连续，还是每个大题独立编号（1 起）？是否检查过题目之间前后透题／重复考点？
- **为什么**：学习通默认按题型连续编号（单选1-8、多选9-12…），答题纸题号跟随试卷。用户明确要求「每个大题独立编号」时，必须在**组卷源头**设置「题目序号：按题型编号」，答题纸编辑器改不了。前后透题（如两题考同一知识点、后题暴露前题答案）要在导入前换题。
- **本次答案**：初版为系统连续编号；用户复核后改为**每大题独立编号**。落地路径：试卷管理复制已发布卷 → 编辑副本设「按题型编号」→ 用副本重新发布，原卷改名标注作废；答题纸自动继承（见 `chaoxing-ops` I11）。检查发现第1题与第14题考点重复，第14题换成振动 RMS／峭度判断题；第13／15题轻微同考点但保留。

## Q9 关键步骤由谁点、哪些要问

- **问**：用户要不要一步一步看、指出按钮位置、关键步骤由用户自己点？
- **为什么**：用户明确："我需要知道大概点在哪儿……一步一步操作，而不是你完全操作完了""关键步骤你得问我一下"。
- **本次答案**：导入提交、发布、发通知三个不可逆点均停下确认；提供 ref／CSS／截图指出位置；用户可自行点。答题纸最后布局微调也由用户自己做（见 Q10）。
- **做法**：默认把不可逆动作列为"需确认"；若用户说"你直接来"，可在非不可逆步骤代为操作，但发布类仍需确认。

## Q10 答题纸最后布局微调归属（用户 2026-11-25 明确决定）

- **问**：答题纸最后的布局微调（跨栏、主观题框大小、均衡、第 4 栏空余）由谁做？
- **为什么**：这是视觉与手写空间的现场判断；实战中 Agent 自动重排曾把 4 栏撑到 5–6 页，且跨栏续写框容易被学生写错位置。用户明确说"太恶心了，我自己调吧，别自动了"。
- **本次答案 / 默认规则**：**用户手动**。Agent 只核对考生信息默认字段（学号+座位号必勾）并打开编辑器，随后 `await task.handOff()` 自动暂停；不自动改 `lineNumber`/`zoneHeight`、不搬题、不删 extra、不改注意事项、不下载 PDF。用户调完说"可以了"再接管完成下载与验证。详见 `execution-flow.md` ④。
- **例外**：只有用户明确说"你来调"时才按 `chaoxing-ops` I12 执行。

## Q11 考试时长与校字71号规范对齐（2026-11-25 复核发现）

- **问**：纸卷上印的考试时长是多少？与超星考试设置是否一致？若为 120 分钟，是否有《120分钟考试时长审批表》（附件2）？
- **为什么**：校字71号第二十条——笔试默认 **90 分钟**，120 分钟须另填审批表。实战中纸卷印"120分钟"而超星发布 90 分钟，学生拿到的卷与系统收卷时间矛盾，属学生可感知硬伤；且未必有审批表。
- **判据**：三份卷（学生卷/标注答案卷/学习通导入版）第4段时长、超星 `limitTime_lx1`、审批表三者必须一致。不一致 → 停下报告用户裁决，不擅自改已发布考试。
- **本次答案**：超星实际 90 分钟（16:00–17:30），纸卷印 120 分钟——**冲突，已记入 `试卷规范归档/.../03_核验记录/已出试卷合规复核报告.md`，待用户决定**。
- **相关**：附件1命题格式几何、主观题≥60%、A/B重复率≤10% 等硬红线见 `试卷规范归档/校字71号-课程考核管理办法/05_原子化规则/试卷规范原子检查清单.md`。
