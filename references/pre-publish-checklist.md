# 发布前终检单

## 用法

**发布按钮点下去之前**，拿这张单子从头到尾核对一遍。每一条都要有页面证据或数据证据（截图／读到的字段值／隐藏 input 值），**不能凭"我记得填过了"**。核对通过 → 向用户复述结论并请求发布授权 → 用户同意才点 `a#submitButton`。

> 为什么必须做：发布后题量、分值、发放对象基本锁死；学生端一旦可见，错误设置会被 63 个（或更多）学生看到。本次实战在最后环节连续暴露了"须知地点丢失""考生人数显示假象""通知写了 A 卷"三个问题，全部靠终检拦住。

---

## A. 系统与试卷

- [ ] **A1** 「线下考试」开关已开启（发布页顶部明确标"线下考试："；字段 `examlx=1`）。
- [ ] **A2** 试卷是目标卷：试卷名／试卷ID 与目标一致（`paperid`／`kssjglid`）。
- [ ] **A3** 题量正确：**24 题**（或本次实际数），导入识别"识别有误 0 题"。
- [ ] **A4** 满分正确：页面显示满分 **100.0**，与分值方案总和 100 一致。
- [ ] **A5** 分值分布已核对：单选 8×2=16、多选 4×2=8、判断 6×1=6、简答 4×10=40、综合 2×15=30，合计 100（分块预览确认）。
- [ ] **A6** 题目内容终检通过：无前后透题／重复考点；更换过的题（如第14题）已是新题；题号连续性符合 Q8 决定。

## B. 考试设置

- [ ] **B1** 考试名称正确；**面向学生文案是否回避 A/B 卷已按 Q6 处理**（系统内部名可保留 A 卷，通知／须知不得出现）。
- [ ] **B2** 考试时间：开始／结束时间正确（本次 2026-11-27 16:00–17:30）。
- [ ] **B3** 答题时长 ≤ 起止时间窗口（本次 90 分钟 ≤ 90 分钟窗口）。注意时长填错会报"时限不能大于起始时间差"。
- [ ] **B4** 及格标准 ≤ 满分（本次 60／100）。
- [ ] **B5** 线下字段用 `_lx1` 后缀的值：`startTime_lx1`／`endTime_lx1`／`limitTime_lx1`／`passingStandard_lx1`；不要读了隐藏的 `startTime`（线上遗留）就以为没填。

## C. 给分与批阅

- [ ] **C1** 多选题给分方式与 Q1 决定一致（本次：未选全得一半分，`multiHalfScoreCheckbox_lx1` 勾选、`multiHalfScore_lx1`=0）。
- [ ] **C2** 纸质卷给分说明已与系统规则同步（"少选得一半、错选 0 分"要补进纸质卷说明）。
- [ ] **C3** 排序题按空给分／填空按空打分（`reviewByBlank`）若涉及，与题目设计一致。
- [ ] **C4** 批阅模式符合 Q2：普通批／流水批，AI 批阅开关状态正确，快速分配方式正确，阅卷教师同步开关正确。
- [ ] **C5** 多人监考／多人共教一门课时，批阅分工已明确并落实。

## D. 发放对象

- [ ] **D1** 班级与人数与 Q4 一致：本次智能23、63 人，隐藏字段 `classids=155688692`。
- [ ] **D2** 若页面显示"已添加考生 0 人"：以隐藏 `classids` 和考生管理页实测人数为准，**不要重复添加**。
- [ ] **D3** 名单在答题纸扫描前已上传完成（若走批量导入，Excel 组别列按行政班划分）。

## E. 学生可见性与须知

- [ ] **E1** 考后查看全部关闭：试卷／提交后答案／截止后答案／总分／对错／答题纸／等级（本次全关，符合 Q3）。
- [ ] **E2** PC 端须知含：考试时间、线下说明、地点（思源楼-120）、主监考姜启龙／副监考王丽。
- [ ] **E3** 移动端须知与 PC 端一致（两端各自一个 UEditor 实例）。
- [ ] **E4** **若从第二步返回过第一步**：重新进入第二步后须知会被 UEditor 重初始化清空——必须重新 `setContent` 补回地点／监考，再核对一次 E2/E3。

## F. 课程／批次／场次（Q7）

- [ ] **F1** 若决定留空：确认 `verifyCourse`/`verifySemester`/`verifyBatch` 均为 0，下拉无数据，`kcid`/`kspcid`/`ksccid` 为空不会校验失败。
- [ ] **F2** 若决定填：下拉有对应数据且已选中，不是只显示了默认文本。

## G. 发布动作

- [ ] **G1** 以上 A–F 全部有证据通过。
- [ ] **G2** 已向用户复述终检结论，并**取得明确发布授权**。
- [ ] **G3** 用户要求自己点时，已指出发布按钮位置（第二步右下角 `a#submitButton`，第一步隐藏），由用户点击。
- [ ] **G4** 发布成功弹窗出现后，按用户决定处理"是否发放考试通知"。

## 发布后验证（不算终检，但必须做）

- 考试管理列表出现该考试，状态"未开始"，考试码已生成（本次 t5709368），考生人数 63。
- 考试答题纸入口可用（每场考试一一对应）。
- 学生端通知已收到且文案符合 Q6（抽样确认）。
